# Panel de gestión · Casa-Pulpería Ezequiel Zamora

Entorno React + Vite + Tailwind CSS para el cliente: acceso con login, métricas rápidas y carga de artículos.

## Arranque

```bash
cd admin
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173).

## Acceso de demostración

- Correo: `admin@casazamora.ve`
- Clave: `zamora2026`

La sesión y los artículos se guardan en `localStorage` hasta conectar el API Go (`localhost:8080`, proxy `/api` ya configurado en Vite).
